### Highlight Projects

- **[oxide-kv](https://github.com/yudhapakel/oxide-kv):** Lightweight in-memory key-value data store built with Rust, implementing asynchronous TCP networking, streaming RESP protocol parser, AOF (Append-Only File) persistence, key expiration (TTL), and glob pattern matching.
- **[himari-engine](https://github.com/yudhapakel/Himari-Ai):** High-performance local voice companion and desktop assistant built in Rust, powered by offline LLMs (Qwen 2.5 via Ollama), in-memory low-latency speech synthesis (VOICEVOX), Win32 hardware telemetry, and an interactive Cyberpunk Canvas HUD.
- **[docktop](https://github.com/yudhapakel/docktop):** Terminal User Interface (TUI) for Docker container inspection, image management, and system metrics visualization built in Go with Bubble Tea and Lip Gloss.
- **Fisight:** Automated fish quality classification system designed for seafood distribution supply chains (FastAPI + MobileNetV2 + MySQL).
- **Harvesta:** End-to-end digital agricultural marketplace and supply platform (Laravel API + Next.js).
- **WEB-HMRPL:** Official web portal of the Software Engineering Student Association at Telkom University. Contributed as Backend Engineer and QA Tester to design robust REST APIs and ensure production system reliability.
