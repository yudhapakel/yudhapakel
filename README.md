### Selected Projects

- **[oxide-kv](https://github.com/yudhapakel/oxide-kv)**  
  In-memory key-value store built in Rust implementing the Redis Serialization Protocol (RESP). Features asynchronous TCP I/O via Tokio, concurrent thread-safe state, active/passive TTL key expiration, and Append-Only File (AOF) persistence.

- **[docktop](https://github.com/yudhapakel/docktop)**  
  Keyboard-driven Terminal User Interface (TUI) in Go for container lifecycle management and host metrics visualization, built on Bubble Tea and the Docker Engine API.

- **[himari-engine](https://github.com/yudhapakel/Himari-Ai)**  
  Local, offline voice assistant runtime written in Rust. Integrates local LLM inference (Ollama), zero-disk in-memory audio playback (VOICEVOX + Rodio), and Win32 hardware telemetry with an Axum-powered Web HUD.

- **[WEB-HMRPL](https://github.com/yudhapakel/WEB-HMRPL)**  
  Official web portal for the Software Engineering Student Association (HMRPL) at Telkom University. Handled backend REST API design, integration testing, and production deployment.
